# Clínica Fluxo

Após concluir e verificar uma alteração de código neste projeto, faça commit dos arquivos pertinentes e envie para `main` em `https://github.com/danilocaldas71-jpg/clinica.git`. O usuário já autorizou commits e pushes para esse destino. Preserve as alterações remotas e use push normal, sem forçar.

Publique apenas código, documentação e testes. Mantenha bancos, backups, credenciais e dados de pacientes fora do repositório.
